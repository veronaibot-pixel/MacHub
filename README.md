# MacHub

Bộ công cụ trên thanh menu macOS (macOS 13 trở lên, Apple Silicon & Intel):

- **Bố cục Desktop**: lưu & khôi phục vị trí, kích thước, Desktop của từng cửa sổ.
- **Wi-Fi dự phòng**: mất mạng LAN → tự chuyển sang Wi-Fi tốt nhất, LAN có mạng lại → tự quay về.
- **Chặn tự mở khi khởi động**: chọn app không được tự mở lại sau khi khởi động lại máy.

## Tải về
Vào mục [Releases](../../releases/latest), tải file `MacHub-<phiên bản>.dmg`, mở ra và kéo MacHub vào thư mục Applications.
Hướng dẫn chi tiết có trong file DMG.

Từ bản 1.1, MacHub tự kiểm tra và cài bản cập nhật mới (Cài đặt chung → Cập nhật).
